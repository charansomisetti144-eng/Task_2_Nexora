The objective of this task is to create a responsive webpage using **HTML, CSS, and Bootstrap/Tailwind CSS**.

## JavaScript Features

### Add to Cart

When the user clicks the **Add to Cart** button:

1. The cart counter increases.
2. The selected product is added to the simulated cart.
3. The button temporarily displays an "Added" message.
4. A success notification appears on the screen.

This functionality is implemented using Vanilla JavaScript.

### Wishlist Toggle

Users can click the heart icon on product cards to add or remove products from the wishlist.

```text
♡ → ♥
```

### Newsletter Validation

The newsletter form validates the email address entered by the user.

It checks for:

- Empty input
- Invalid email format
- Valid email format

A success message is displayed when a valid email address is submitted.

## Responsive Design

The webpage was designed using the **Bootstrap 5 responsive grid system** along with custom CSS media queries.

The website adapts to:

- Desktop screens
- Laptops
- Tablets
- Mobile phones

On smaller screens:

- The navigation changes to a hamburger menu.
- Product cards rearrange automatically.
- Category cards adjust according to screen size.
- Hero content adapts for better readability.
- Newsletter and footer layouts become mobile-friendly.

Alternatively, `index.html` can be opened directly in a modern web browser.

No additional installation or build process is required.
