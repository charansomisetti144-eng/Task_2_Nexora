# 🌐 Root Directory

The root directory contains the main project files required to run the website.

### Files

- `index.html`
- `README.md`

### Purpose

- Starts the website.
- Connects CSS and JavaScript files.
- Serves as the entry point of the application.

---

# 🎨 CSS Folder

The **css** folder contains all stylesheet files responsible for the appearance of the website.

### Example

```text
css/
└── style.css
```

### Responsibilities

- Layout design
- Typography
- Colors
- Responsive styling
- Hover effects
- Animations

Keeping CSS separate improves maintainability and organization.

---

# ⚡ JavaScript Folder

The **js** folder contains JavaScript files that provide interactivity to the landing page.

### Example

```text
js/
└── script.js
```

### Responsibilities

- User interactions
- Event handling
- Navigation behavior
- Dynamic UI updates
- Form validation (if implemented)

Separating JavaScript from HTML follows industry-standard development practices.
